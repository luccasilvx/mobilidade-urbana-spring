# Sistema de Mobilidade Urbana — Projeto Integrador Full Stack

Aplicação web desenvolvida em **Java 17** e **Spring Boot 3.3.4** (Spring MVC, Spring Data JPA, Spring Security, Bean Validation), **H2 Database**, **Thymeleaf** e **Bootstrap 5**, modernizando o sistema legado de mobilidade urbana com arquitetura em camadas, regras de transição de status e controle de acesso validado no servidor.

## Pré-requisitos
- Java JDK 17+
- Maven Wrapper incluído no projeto (`./mvnw` ou `.\mvnw.cmd`), dispensando instalação manual do Maven.
